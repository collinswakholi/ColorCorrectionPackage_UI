# Offline reference study

Wakholi, C., et al. (2026). *A systematic color correction pipeline for controlled-environment imaging.* The Plant Phenome Journal, 9, e70067.

[Publisher article](https://acsess.onlinelibrary.wiley.com/doi/full/10.1002/ppj2.70067) · [Publisher PDF](https://acsess.onlinelibrary.wiley.com/doi/pdf/10.1002/ppj2.70067)

The publisher PDF states that the article is open access under the Creative Commons Attribution License. Preserve its attribution and license when distributing a copy.

The application does **not** bundle the paper. For a source build, download it through the publisher in your browser and save it here as `ppj2.70067.pdf`. The in-app **Study PDF** button then opens that local file without internet. Release packaging uses an explicit document list and does not automatically include a downloaded PDF. The embedded illustrated app guide works offline independently of the paper.
