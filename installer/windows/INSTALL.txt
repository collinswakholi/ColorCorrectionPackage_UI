ColorCorrect Studio - Windows 11 x64 or ARM64

Use the installer matching your native Windows architecture, or extract the entire
portable ZIP into a writable folder. Run ColorCorrect-Studio.cmd. The desktop app
does not require Python, Rust, or a separately installed .NET runtime.

The installer checks Microsoft Visual C++ runtime prerequisites. If needed, you
may choose to install the included Microsoft prerequisite; only that action asks
for elevation. A portable installation can run check-system.ps1 first and opt in
with -InstallPrerequisites. Installation never silently downloads a GPU driver.

Setup offers Recommended, CPU only, and Custom installation. CPU inference and
correction are always included. Auto prefers a verified GPU and recovers to CPU.
CPU only skips the optional WebGPU plugin; DirectML.dll may remain because the
shared ONNX Runtime build imports it even for CPU operation.

Portable setup and repair (PowerShell from this folder):
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1 -Diagnose -Verify
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1 -Mode cpu -Install
Use -Mode custom -Components webgpu,directml to select optional engines. The
command previews changes and requests confirmation. Bundled runtimes work
offline. No system graphics driver is installed or replaced. To add a component
omitted during installation, rerun the matching installer using Custom or extract
the full portable ZIP. Check setup in the app diagnoses changes to hardware.
Silent setup accepts /TYPE=recommended, /TYPE=cpu, or /TYPE=custom and explicit
/COMPONENTS=app,directml,webgpu,python. It never elevates VC installation silently.
A restart requested by Microsoft must complete before reliable verification.

Python API (optional, PowerShell from the installation folder):
$wheel = (Get-ChildItem .\python\*.whl).FullName
python -m pip install --no-deps "$wheel"
Pass the installed app folder as root= to Client. Examples are in python\examples.

Uninstalling the app preserves user settings, sessions and saved models. Unsigned
local candidates are not certified releases. Review package-manifest.json and
runtime-support.json for hashes, limitations and outstanding validation gates.
