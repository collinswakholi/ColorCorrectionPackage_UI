ColorCorrect Studio - Linux x64 or ARM64
Ubuntu 24.04 or 22.04, Debian 13 or 12 (glibc 2.35 or newer)

Install the .deb with: sudo apt install ./colorcorrect-studio_*.deb
apt shows and installs the required system libraries.

Portable archive: extract it, then run
  ./check-system                      lists anything missing (changes nothing)
  ./install-dependencies --install    installs the missing libraries with apt
  ./ColorCorrect-Studio               starts the app
check-system also runs each time the launcher starts. If it was started from a
desktop menu, its report is saved to ~/.config/colorcorrect/startup-error.txt.
The desktop app does not require Python, Rust or a separate .NET installation.
No command downloads or changes a GPU driver.

Auto uses compatible GPU inference, otherwise explicit CPU inference. CPU
correction remains available. Inspect device inventory and actual engine results:
./setup --diagnose --verify
./setup --mode cpu --install
./setup --mode custom --components webgpu --install
The command previews changes and asks for confirmation before using apt. It is
never run from a .deb maintainer script. Required libraries remain installed even
in CPU mode. Private runtime payloads are bundled; no driver is installed.
Automatic dependency installation supports Ubuntu 24.04 and 22.04 and Debian 13
and 12. On other distributions, install the libraries check-system lists with
your package manager. Native Wayland is not certified; this version uses
X11/XWayland.

WSL GPU support is an optional experimental x64 add-on. If included, enable it
with ./wsl-gpu-setup enable and restart the app/client. Disable it with
./wsl-gpu-setup disable. It only affects the ColorCorrect worker, never system
Mesa or global Vulkan configuration. WSL 2, /dev/dxg, WSL graphics libraries and
a compatible Windows GPU driver are required. ARM64 WSL add-on support is pending.
If an enabled add-on is missing or fails validation, the worker continues with
the standard runtime so CPU operation and Auto recovery remain available.
Check setup shows the GPU failure; repair the matching add-on or run
./wsl-gpu-setup disable before restarting the app/client.

Python API (optional): python3 -m pip install --no-deps python/*.whl
Pass this app folder as root= to Client; examples are in python/examples.

Uninstalling preserves user settings/models/sessions. To disable an add-on after
uninstalling, remove ~/.config/colorcorrect/wsl-gpu.enabled (or the equivalent
XDG_CONFIG_HOME path). Do not remove the legacy CCP-New application data folder.

These are local release candidates. Native hardware/architecture support remains
pending until the corresponding acceptance evidence is reviewed. See
runtime-support.json, dependency-report.json and package-manifest.json.
