Optional ColorCorrect Studio CUDA runtime add-on (development artifact).

This installs official LibTorch 2.9.1/cu126 into the separate per-user
CCP-New/libtorch-cuda folder. It does not delete or replace app-local CPU libraries
or the older per-user libtorch folder. Existing destinations are refused.

Use the in-app runtime manager or install_libtorch_cuda.ps1 to reuse a valid tree.
Each worker loads one runtime. CUDA affects selected detector/LUT operations,
not NN training or every stage; inspect actual backend telemetry.

No optional CUDA add-on executable is published with v0.1.0.
