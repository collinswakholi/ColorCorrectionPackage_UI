# Bundled notices

Build scripts copy full upstream LibTorch, ONNX Runtime, DirectML and .NET
notices here, plus the licensed VC runtime inventory. The release build also
records locked Rust/NuGet dependencies. These generated files belong in the
installer and release provenance, not as stale copies of a developer's machine.

See [THIRD_PARTY_NOTICES](../THIRD_PARTY_NOTICES.md) and the
[model provenance disclosures](../docs/model-provenance.md). Review the notices,
source-access information and redistribution obligations of all shipped
dependencies and detector weights before publication. FFmpeg/ffprobe and video
processing are not included in this still-image-only preview.
