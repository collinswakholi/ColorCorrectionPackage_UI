# Dependency notices

The project MIT license covers project source. Runtime dependencies and detector models retain their own terms. See [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) and [model notices](../models/NOTICE.md).

Package staging must copy the licenses and third-party notices shipped in the verified runtime archives, along with architecture-correct native libraries. Do not substitute this inventory for the upstream license text or infer complete redistribution rights from a source-code license. Keep dependency versions, download URLs and SHA-256 values in the package manifest.

Public redistribution review remains separate from local validation. No automatic signing or publication is performed.
